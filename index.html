Personal Google Drive Backup

This setup uses rclone to back up files from a computer or server I control to my own Google Drive. It is for my personal use and is not offered as a service to other users.

Rclone runs on the computer or server where it is installed. This website does not run the backup, receive files, or store Google Drive data.
